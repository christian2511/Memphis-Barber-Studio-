# Memphis Barber Studio Website

A static website concept for Memphis Barber Studio. It uses plain HTML, CSS, and JavaScript, so no backend or installation is required.

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload `index.html`, `barbers-at-work.webp`, and `pool-table-studio.webp` to the main level of the repository.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then press **Save**.

The website will appear at the GitHub Pages address shown in Settings.
